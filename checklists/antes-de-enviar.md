# Antes de enviar

## O arquivo

- [ ] Assisti até o fim, com som, no computador e no celular.
- [ ] O vídeo abre, tem imagem e som do começo ao fim.
- [ ] Os textos continuam legíveis na tela do celular.
- [ ] O nome do arquivo está claro.

## Direitos

- [ ] Se há música, ela tem licença para este uso. A trilha do exemplo é só para uso nêo comercial.
- [ ] Efeitos, fontes, imagens e logo podem ser usados aqui.
- [ ] Li [AVISOS.md](../AVISOS.md).

## Conteúdo

- [ ] Nada promete resultado que eu nêo consigo provar.
- [ ] Números e telas foram conferidos de novo.
- [ ] Nenhum dado pessoal aparece.

## Se o filme é de outro negócio

- [ ] Está marcado como amostra nêo oficial e tem de 5 a 15 segundos.
- [ ] Vou enviar só em privado, para uma pessoa.
- [ ] Conferi as regras da marca.
- [ ] Nêo publiquei em lugar nenhum, nem no portfólio.
- [ ] A mensagem é curta e nêo promete resultado.
- [ ] Vou mandar no máximo um lembrete, depois de uma semana.
- [ ] Se houver sim, vou combinar os detalhes por escrito antes de publicar.
