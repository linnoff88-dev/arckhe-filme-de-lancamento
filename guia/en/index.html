How to start

How to start

The AI reads the kit, explains the steps, and asks for your approval before changing anything.

1

Open the kit folder in Claude

On Windows or Mac, install the Claude app, sign in, and subscribe to a plan before opening the Code tab. Download the kit from GitHub using the Code and Download ZIP buttons, then unzip it. In the app, open the Code tab, choose Local, and use Open folder… to select the folder that contains COMECE-AQUI.md. You do not need the terminal. This is the official path, but it has not been tested with the kit yet. On Linux, where the kit was tested, the full instructions show how to open it.

2

Paste the prompt

It helps the AI learn about the kit and ask about your business. To send photos and your logo, drag the files into the chat or tell the AI where they are, and ask it to organize them. The kit's prompts are written in Portuguese, and the AI can walk you through them in English.

3

Say yes when it makes sense

The AI guides you one step at a time. To continue, just say "follow the file prompts/P1", and so on, without opening any files. You approve the story, the images, and each change.

Read COMECE-AQUI.md and this project's prompts/ folder. Then explain in simple language how we will make a launch film about 30 seconds long for my business. Check what needs to be installed using the technical installation section of the README, and ask for my approval before installing anything. Ask one question at a time about the business, the problem it solves, and the real photos, screens, and numbers I have. Do not change any files before I say yes. Do not publish or send anything. Questions

Common questions

What people often ask before they start.

Do I need to know how to code?

Not to direct the film: you talk with the AI. The AI handles the technical part, but you need to have Claude Code installed and approve what it does.

Do I need to know how to edit video?

No. You look at it, say what you want to change, and point to the second.

How much does it cost, and what do I need?

The kit is free, and the film is made on your own computer. The cheapest plan with Claude Code, Pro, cost US$ 20 per month on 18/11/2026 with monthly billing. With annual billing, it cost US$ 17 per month, with US$ 200 paid upfront. Check the current price on the official pricing page.

The same page says you can cancel at any time in Settings > Billing, and your plan stays active until the end of the paid period. To avoid the next charge, cancel at least 24 hours before renewal.

Every plan has a usage limit, and we have not measured how much one film uses. If you run out, check Settings > Usage to see when it renews, wait, and continue in the same folder.

The AI may need to install free programs, and you approve each one first: Node.js runs the program that puts the film together, FFmpeg combines image and sound, Chrome draws each frame, and Python measures the music if you use any.

Will it work on my computer?

The kit was tested on Linux. Claude has official installations for Windows and Mac, but the kit has not been tested on them yet. Before you pay, check the official Claude Code minimum requirements: Windows 10 version 1809 or newer, or macOS 13 or newer, with 4 GB of memory, an x64 or ARM64 processor, and internet access. Meeting these minimums does not guarantee the film will work, and the minimum requirements for making it have not been measured.

Try this first: ask the AI to make the example film without changing anything. If it fails, copy the error message to the AI and try once. If that does not fix it, stop. There is no guarantee it will work on your computer.

How do I move the video to my phone?

Ask the AI to open the folder with the finished video. Then send the file to yourself using WhatsApp Web or email, and download it on your phone. The film is landscape; the portrait format has not been tested with the kit yet.

Can I use the example's music for my business?

No. It is for non-commercial use only. Your film can be made without music, with sound effects only. If you want music, one example is Incompetech: on 18/11/2026, the site listed a license that allows commercial use with credit to the author. Read the license before using it.

Can I make a film for someone else's brand?

As a private sample, marked as unofficial, using the official logo without changing it. Do not use other people's photos without permission or show customers' or employees' faces. Public app screens can be used only in the private sample. For a creator, use text, illustration, and their public name. If the business has no published brand rules, use the logo from its own website or profile and ask for permission before any public use.

Does this guarantee customers?

No. The kit helps you show what you have more clearly.
